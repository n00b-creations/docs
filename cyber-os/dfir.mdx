# DFIR Workspace

The DFIR profile is organized around investigation state, evidence integrity, timeline correlation, and case documentation.

## Core widgets

- Active cases
- Evidence locker
- Chain-of-custody ledger
- Forensic timeline
- Artifact browser
- Host and user activity
- File metadata and hashes
- Investigation notes
- Case report builder

## Investigation model

Evidence is tracked as case-scoped objects with provenance, timestamps, analyst notes, and status. Timeline events can be filtered and correlated across hosts, users, files, authentication, network activity, and alerts.

The prototype uses synthetic data and does not access or alter real evidence.
