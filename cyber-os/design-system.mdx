# CYBER-OS Design System

## Visual language

CYBER-OS uses a near-black operations-console foundation with technical panel borders, monospace-oriented typography, compact density, and restrained semantic accents.

## Tokens

### Color roles

- Background: near-black surfaces.
- Primary: cyber green for active states and telemetry.
- Info: cyan for navigation and neutral system information.
- Warning: amber for degraded state and attention.
- Critical: red for security and operational faults.
- Purple: Purple Team and correlation workflows.

### Component families

- Workspace switcher
- Dockable panel
- Panel header
- Tabs
- Metric card
- Status badge
- Data table
- Timeline event
- Graph node and edge
- Drawer
- Modal
- Command palette
- Workflow node
- Tool card
- Note editor
- Notification

## Interaction principles

Every major visualization exposes selection, filtering, drill-down, or contextual actions. Workspace changes should preserve the user's layout and theme preferences while swapping the operational composition.

## Accessibility

Use semantic labels, visible focus states, sufficient contrast, keyboard navigation, and non-color indicators for critical state.
